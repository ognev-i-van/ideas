# Пересылка пушей с iPhone в вебхук (Mattermost / Slack / Telegram)

Инструкция по настройке автоматизации в приложении «Команды» (Shortcuts): каждый пуш выбранного приложения (например, банка) отправляется POST-запросом на вебхук. Так можно получать операции по карте без API банка.

> **Для ИИ-ассистента.** Проведи пользователя по шагам ниже по одному, на каждом шаге проси подтвердить или прислать скриншот. Названия пунктов даны по английскому интерфейсу, в скобках — русский. Самые частые ошибки разобраны в разделе «Если не работает».

## Что понадобится

- iPhone со свежей iOS, где в автоматизациях есть триггер **Notification** («Уведомление»).
- Приложение, чьи пуши пересылаем, с включёнными уведомлениями.
- URL входящего вебхука:
  - **Mattermost**: Интеграции → Входящие вебхуки → Добавить. Получится `https://<ваш-сервер>/hooks/<id>`.
  - **Slack**: Incoming Webhooks. Получится `https://hooks.slack.com/services/...`.
  - **Telegram**: бот от @BotFather и ваш `chat_id`. URL: `https://api.telegram.org/bot<TOKEN>/sendMessage`.

URL вебхука — это секрет. Любой, у кого он есть, может писать в ваш канал. Не публикуйте его на скриншотах.

## Шаг 1. Создать автоматизацию

1. **Shortcuts → Automation** («Команды» → «Автоматизация») → **+**.
2. Выберите триггер **Notification** («Уведомление»).
3. В поле **from** укажите приложение-источник.
   - У ТБанка приложение в App Store может называться иначе, чем банк. Выбирайте то, от которого приходят пуши.
4. Включите **Run Immediately** («Запускать сразу») и выключите уведомление о запуске. Иначе команда будет каждый раз спрашивать подтверждение.
5. **Next** → **New Blank Shortcut** («Новая пустая команда»).

## Шаг 2. Достать текст уведомления

Добавьте действие **Text** («Текст») и вставьте в него переменную **Notification**: нажмите в поле, выберите её над клавиатурой.

Должно получиться:

```
Text
  [Notification]
```

## Шаг 3 (необязательно). Отфильтровать лишнее

Например, чтобы не пересылать ежедневные «Выписка от …» с начислением кэшбэка:

1. Добавьте действие **If** («Если»).
2. Условие: переменная **Text** → **contains** («содержит») → `Выписка`.
   - Берите именно **жёлтую** `Text` — это вывод действия из шага 2.
3. Внутрь `If`, до `Otherwise`, добавьте действие **Stop this shortcut** («Остановить эту команду»).
4. Ветку `Otherwise` («Иначе») оставьте пустой.

Если стоп-слов несколько, добавьте в `If` ещё условия кнопкой **+** и переключите режим на **Any** («Любое»).

## Шаг 4. Отправить в вебхук

Добавьте действие **Get contents of URL** («Получить содержимое URL») **после** `End If`. Раскройте его стрелкой и заполните:

| Поле | Значение |
|---|---|
| URL | ваш URL вебхука |
| Method | `POST` |
| Headers | ничего не добавлять |
| Request Body | `JSON` |

Поля JSON зависят от сервиса.

**Mattermost / Slack** — одно поле:

| Ключ | Тип | Значение |
|---|---|---|
| `text` | Text | переменная **Text** (жёлтая) |

**Telegram** — два поля:

| Ключ | Тип | Значение |
|---|---|---|
| `chat_id` | Text | ваш chat_id |
| `text` | Text | переменная **Text** (жёлтая) |

Экранировать текст не нужно: «Команды» сами соберут корректный JSON.

Чтобы слать сразу в несколько мест, добавьте второе действие **Get contents of URL** со своим URL и полями.

## Итоговая схема

```
When I receive a notification from <приложение>     (Run Immediately)
Text
  [Notification]
If [Text] contains "Выписка"
  Stop this shortcut
Otherwise
End If
Get contents of https://<ваш-сервер>/hooks/<id>
  Method: POST
  Request Body: JSON
    text = [Text]
```

## Проверка

1. Убедитесь, что вебхук жив. С компьютера:

   ```bash
   curl -X POST -H 'Content-Type: application/json' \
     -d '{"text":"тест"}' https://<ваш-сервер>/hooks/<id>
   ```

   В канале должно появиться «тест».
2. Сделайте небольшую операцию или дождитесь пуша от приложения. Его текст должен прийти в канал.

## Если не работает

| Симптом | Причина и решение |
|---|---|
| В `If` у переменной `Text` зелёная иконка и «Variable not available» | Выбран вывод действия **Get contents of URL**, которое идёт позже. Нажмите на переменную → **Clear Variable** → выберите жёлтую **Text** из шага 2. |
| Отфильтрованные пуши всё равно приходят | Внутри `If` нет **Stop this shortcut**, или стоп-слово не входит в текст: оно может быть в заголовке пуша, а не в теле. Добавьте условие по слову из тела. |
| В канал приходит пустое сообщение или что-то странное | В поле `text` подставлена не та переменная. Нужна жёлтая **Text** или **Notification**. |
| Команда спрашивает подтверждение перед запуском | В автоматизации не включён **Run Immediately**. |
| Ничего не приходит вообще | Проверьте вебхук через `curl`. Проверьте, что уведомления приложения включены и пуш действительно пришёл. |
| Telegram отвечает ошибкой | Неверный `chat_id`, или вы не написали боту `/start`. |
